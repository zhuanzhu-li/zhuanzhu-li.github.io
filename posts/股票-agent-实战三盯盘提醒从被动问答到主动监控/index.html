前言

前两课的 agent 都是被动的：你问它才答。这一课把它变成主动的：不用问，条件触发了它自己来提醒你。

这一课也顺便回答一个常见误区：不是所有环节都需要大模型。数值条件（跌破某个价、跌幅超过 3%）用规则引擎最可靠、最快、零成本、可评测。模型的价值在「解读」，不在「触发」。

一、场景：条件触发提醒

盯盘要解决三件事：

  1. 条件评估：价格跌破 1400、跌幅超过 3%、涨幅超过 5%……这些是纯数值判断；
  2. 触发一次：价格在 1399 附近反复震荡，不能每分钟都发一条「跌破了」——要等条件先消失、再触发才算新一轮；
  3. 通道通知：提醒要送到人那里，控制台、企业微信、邮件、钉钉，通道可以换。

二、实现：纯函数规则引擎

条件评估写成无副作用的纯函数，不碰网络、不碰 IO，因此可以离线测试、跑得飞快：

@dataclass(frozen=True)
class Condition:
    type: str      # price_below / price_above / change_pct_below / change_pct_above
    value: float

    def hit(self, quote: dict) -> bool:
        price = _to_float(quote.get("最新价"))
        change = _to_float(quote.get("涨跌幅"))
        if self.type == "price_below":
            return price is not None and price < self.value
        if self.type == "change_pct_below":
            return change is not None and change < self.value
        ...

触发状态机是这节课的关键设计：命中且未触发 → 发提醒并置位；不再命中 → 复位。这样同一条件不会反复刷屏，价格回落再跌破又能重新提醒：

for cond in item.conditions:
    key = (item.symbol, cond.type, cond.value)
    hit = cond.hit(quote)
    if hit and not state.get(key, False):
        state[key] = True
        alerts.append(format_alert(name, item.symbol, cond, quote))
    elif not hit:
        state[key] = False

三、通知通道抽象

提醒内容与「送到哪里」解耦。默认控制台，配置了企业微信机器人 webhook 就走 webhook，邮件/钉钉以后照葫芦画瓢：

class Notifier:
    def send(self, message: str) -> None: ...

class ConsoleNotifier(Notifier):
    def send(self, message: str) -> None:
        print(f"[{datetime.now():%H:%M:%S}] {message}")

class WebhookNotifier(Notifier):
    def send(self, message: str) -> None:
        requests.post(self.url, json={"msgtype": "text", "text": {"content": message}})

def build_notifier() -> Notifier:
    url = os.getenv("WECHAT_WEBHOOK_URL", "").strip()
    return WebhookNotifier(url) if url else ConsoleNotifier()

盯盘清单用 JSON 配置，改条件不用改代码：

{
  "items": [
    {
      "symbol": "600519",
      "conditions": [
        { "type": "price_below", "value": 1400.0 },
        { "type": "change_pct_below", "value": -3.0 }
      ]
    }
  ]
}

四、运行与验证

# 单轮检查（演示用）
conda activate stock-agent   # 每次开新终端先切换环境
python stock-agent/monitor.py --once

# 持续轮询（默认 30 秒一次）
python stock-agent/monitor.py --interval 30

真实触发输出：

[10:38:52] [盯盘提醒] 贵州茅台(600519) 跌破 1400.0：现价 1342.99，涨跌幅 -0.44%

离线测试新增 6 项（条件命中/不命中、触发一次与回落复位、告警格式、清单解析、未知条件启动即报错），总数来到 13 项，全部不联网、不花钱。

五、小结

第三课的收获：

  1. agent 化不等于全部用 LLM——数值规则用纯函数，可靠、可测、零成本；
  2. 触发状态机——「命中置位、回落复位」避免重复轰炸，这是监控系统的通用设计；
  3. 通道抽象——提醒内容与通知方式解耦，控制台/企业微信/邮件/钉钉可插拔；
  4. fail fast——未知条件在启动时报错，而不是在盘中悄悄失效。
