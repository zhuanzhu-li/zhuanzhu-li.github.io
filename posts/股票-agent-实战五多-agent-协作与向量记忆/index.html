前言

前四课给一个 agent 装了四个器官：行情、财报、舆情、盯盘。但让一个 agent 同时扮演分析师、审计师、观察员，提示词会越来越臃肿，工具越堆越乱。这一课做两件事：专业分工（多 Agent）和跨问题记忆（向量记忆）。

一、多 Agent：专业分工

三个专业 agent，各带各的工具、各讲各的话：

角色 专属工具 职责
行情分析师 实时盘口、日 K 线 价格、走势、量能
财报解读师 财务摘要 营收/净利增速、盈利能力、负债
舆情观察员 新闻情绪 市场情绪、主要事件

谁上场用规则路由决定——关键词命中就派对应角色，没命中三个都上：

def route_question(question: str) -> list[str]:
    matched = [
        role for role, cfg in ROLES.items()
        if any(keyword in question for keyword in cfg["keywords"])
    ]
    return matched or [ROLE_MARKET, ROLE_FUNDAMENTAL, ROLE_SENTIMENT]

每个专业 agent 是 harness Agent 的普通实例，只是系统提示词和工具注册表不同：

def build_specialist(client, role: str) -> Agent:
    cfg = ROLES[role]
    registry = ToolRegistry()
    for tool_impl in cfg["tools"]:
        registry.register(tool_impl)
    return Agent(client=client, registry=registry, system_prompt=cfg["system"])

二、首席分析师：汇总成结构化结论

专业 agent 各自调研完后，由「首席分析师」汇总。汇总阶段用第二课的结构化输出，强制产出 answer / sections / confidence：

REPORT_SCHEMA = OutputSchema(
    fields={
        "answer": as_str,      # 给用户的完整回答
        "sections": as_list,   # 分点结论
        "confidence": as_str,  # 高 / 中 / 低
    },
    required=["answer", "sections", "confidence"],
)

真实运行示例（贵州茅台）：

综合：茅台处于“提价驱动+资金回流”的积极窗口期，但基本面增长已明显放缓。
- 行情：股价 1339.99 元，跌 0.66%，1338-1353 元窄幅整理，量能低迷。
- 财报：2025 年营收 -1.20%、净利 -4.53%；2026Q1 营收 +6.34% 但净利仅 +1.47%。
- 舆情：飞天茅台连续提价，主力净流入约 4.89 亿元，情绪偏积极。
结论置信度：中

三、向量记忆：跨问题复用历史结论

多 Agent 解决了「分工」，记忆解决「连续性」：问过一次茅台，下次再问相关问题时，把历史结论找回来作为参考。

设计上先用 Embedder 协议隔离具体嵌入实现：

class Embedder:
    def embed(self, texts: list[str]) -> list[list[float]]: ...

class CharNgramEmbedder(Embedder):        # 默认：字符 bigram 哈希，离线、可复现
    ...

class SentenceTransformerEmbedder(Embedder):  # 生产：多语言语义模型，需下载
    ...

VectorMemory 只依赖协议：写入时嵌入并保存，查询时嵌入后做余弦相似度检索，支持 JSON 持久化。向量规模大了可以无缝换 faiss 索引（环境已预装）。

memory = VectorMemory.load(path, CharNgramEmbedder())
memory.add(f"Q: {question}\nA: {answer}", {"type": "analysis"})
hits = memory.search("贵州茅台财报基本面怎么样", top_k=2)

真实验证：存入一次茅台分析后，用新问题检索，正确召回历史结论，相似度 0.20。

四、运行与验证

# 多 Agent 协作
conda activate stock-agent   # 每次开新终端先切换环境
python stock-agent/team.py "贵州茅台最近怎么样？"

# 多 Agent + 向量记忆（默认离线嵌入；生产可加 --embedder st）
python stock-agent/team.py --memory stock-agent/memory_store.json "贵州茅台最近怎么样？"

离线测试从 18 项增至 23 项（新增：角色路由、报告 Schema 校验、记忆检索、持久化往返）。

这一课又踩了两个真实坑，都成了教学素材：

  1. 日期对象序列化——真实 K 线的日期列是 date 对象，json.dumps 直接崩；数据源层统一转字符串，并把测试数据改成真实类型防止回归；
  2. 嵌入模型下载受限——当前网络连不上 HuggingFace（镜像也超时），于是默认嵌入器改为离线的字符 n-gram，生产环境一条命令换回语义模型——这就是协议抽象的价值。

五、小结

第五课的收获：

  1. 多 Agent 的价值是分工，不是堆模型——每个 agent 只有自己的工具和职责，提示词保持简单；
  2. 规则路由 + 结构化汇总——谁上场用规则（可测），结论怎么出用 Schema（可消费）；
  3. 记忆的关键是协议——嵌入模型可插拔，记忆逻辑不绑定任何具体模型；
  4. 真实环境会教你取舍——下载不了的模型，用一个可复现的轻量替代，照样跑通全链路。
