前言

前三课，agent 知道了「是什么」：价格多少（行情）、公司赚不赚钱（财报）、跌破没跌破（盯盘）。这一课补上「为什么」：市场在说什么、情绪往哪边偏——新闻与舆情。

一、数据源调研：又踩到一个上游 bug

第一件事是验证舆情数据源。AkShare 有个个股新闻接口 stock_news_em，一跑就报错：

ArrowInvalid: Invalid regular expression: invalid escape sequence: \u

翻了源码：接口在清洗标题时用了 str.replace(r"\u3000", "", regex=True) 这类正则，在 pandas 3.0 / pyarrow 下属于非法转义——AkShare 的上游 bug，不是我们的问题。

处理方式和第一课「UA 断连」一模一样：数据源层直连 HTTP。东方财富的新闻搜索接口直接返回 JSONP，自己解析、自己清洗 <em> 高亮标签，工具层和 agent 完全无感：

def news_list(symbol: str, limit: int = 10) -> list[dict]:
    """个股新闻列表（直连东方财富搜索接口）。"""
    ...
    return [
        {"title": _strip_em(row["title"]), "source": row["mediaName"], "time": row["date"]}
        for row in rows[:limit]
    ]

第一课的分层哲学在这里第二次兑现：库坏了，换实现，上层不动。

二、情绪评分：规则优先，模型解读

「情绪」先给一个确定性定义，用词典规则：标题命中「利好、涨价、增持、超预期…」记正面，命中「亏损、减持、立案、暴雷…」记负面，谁多算谁；再聚合出 score ∈ [-1, 1]：

def classify_title(title: str) -> str:
    pos = sum(1 for w in POSITIVE_WORDS if w in title)
    neg = sum(1 for w in NEGATIVE_WORDS if w in title)
    return "positive" if pos > neg else "negative" if neg > pos else "neutral"

def score_news(news):
    score = (positive - negative) / max(1, len(news))  # [-1, 1]

延续第三课的原则：评分是规则的事（可靠、可测、零成本），解读才是模型的事。agent 拿到 score 和新闻列表后，用自然语言解释「为什么偏积极」。

三、工具：get_news_sentiment

与前面的工具完全同构，注册进同一个注册表，问答 agent 就多了一个器官：

@tool(
    name="get_news_sentiment",
    description="获取 A 股个股最近的新闻标题并给出情绪评分（score 范围 -1~1，>0 偏积极），"
                "返回正/负/中性新闻数量与新闻列表，用于舆情分析。",
    parameters={
        "type": "object",
        "properties": {
            "symbol": {"type": "string", "description": "6 位 A 股股票代码"},
            "limit": {"type": "integer", "description": "取最近 N 条新闻，默认 10，最多 30"}
        },
        "required": ["symbol"],
    },
)
def get_news_sentiment(symbol: str, limit: int = 10) -> dict:
    return score_news(data_source.news_list(symbol, limit))

四、运行与验证

conda activate stock-agent   # 每次开新终端先切换环境
python stock-agent/main.py "贵州茅台最近有什么新闻？市场情绪怎么样？"

真实输出要点：

核心事件：飞天茅台连续提价（i茅台 1539→1639 元，自营店涨至 1753 元/瓶）
资金动向：8月10日主力净流入 4.89 亿元，食品饮料板块流入居前

情绪评分：+0.2（偏积极）｜ 正面 5 条 / 负面 3 条 / 中性 2 条
情绪解读：提价利好是主要正面驱动，白酒板块资金流出带来负面扰动，多空交织。

离线测试从 13 项增至 18 项（新增：词典分类、聚合评分、工具输出与标签清洗），全部不联网。

五、小结

第四课的收获：

  1. 舆情数据源同样会踩坑——上游库在版本升级后坏掉是常态，数据源层直连 HTTP 是第二道保险；
  2. 情绪评分用词典规则——确定性、可测、零成本，评分与解读分工明确；
  3. 工具注册即能力——agent 每多一个工具就多一种感知，架构不需要变；
  4. 两个真实小坑——Windows 控制台 GBK 编码遇到 ⚠ 会崩（reconfigure(errors="replace") 解决）、漏 import json——都被 harness 的「工具出错返回文本」设计兜住了，agent 从容转向其他工具。

下一步：记忆与多 Agent——把对话记忆升级为向量记忆（环境里已备好 faiss / sentence-transformers），并让「行情分析师」「财报解读师」「舆情观察员」各司其职、协作回答。
